## Release focus
Version **0.2.02 (2026-03-02)** was a **minor release** focused primarily on bugs discovered during testing and tightening reliability in daily operation.

## HUDs impacted
- Settings HUD (Recovery actions, schedule/config flow)
- Notifications HUD (crash-safe item mapping)
- Files HUD / transcript rendering paths

## Changed
- Recovery primary actions were updated to `New Backup`, `Set Schedule`, and `Config`, with `Folder` and `Scan Files` moved into Config.
- Backup scheduling UX moved to a dedicated Recovery schedule dialog (aligned with optimizer style), with defaults:
  - `02:00` -> `05:00`
  - `When plugged in` enabled
- Scheduled backup execution now consistently honors configured window/charging settings in both app-side checks and background worker runs.
- Scheduled optimizer safeguards were tightened to skip desktop sync when local Wi-Fi/Ethernet + subnet match is not available for the configured desktop IP, with cooldown backoff to avoid repeated failed attempts.

## Fixed
- Fixed Notifications HUD crash on main thread when mapping non-resource `smallIcon` metadata (`Icon.TYPE_BITMAP`) by safely checking icon types and skipping malformed items.
- Fixed long-segment rollover stability by preventing double rollover/start sequences during adaptive and hard-stop paths.
- Fixed forced hard-stop persistence to avoid writing placeholder transcript text as final transcript.
- Fixed transcript fallback behavior so legacy placeholders (`[Transcript unavailable: forced segment rollover]`) no longer block loading transcript text from files.
- Fixed adaptive long-speech rollover on weaker VAD callback devices by adding partial-transcript speech-activity fallback.

## Feedback
This release was intentionally low-scope and reliability-first. The goal was to resolve testing regressions quickly before expanding feature surface again.
