## Release focus
Version **0.2.00 (2026-02-28)** marked a major identity transition and stack realignment.

### Special note: Walker Brain -> Walker XR
This release marks the transition from **Walker Brain** to **Walker XR**.

The renaming reflects product reality: the augmented-reality app used with **XREAL One glasses** is now the primary user-facing experience, so `Walker XR` is the right identity for the mobile AR client.

The `brain` concept remains valid, but it now maps better to companion local applications that handle heavier processing workloads.

![Walker XR logo](/images/process/walker-xr-logo.png)

## HUDs impacted
- Settings HUD (Recovery first-run import guidance)
- App-wide branding surfaces (titles/status text)

## Changed (Walker XR app)
- Technical identity changed from `Walker Brain` to `Walker XR` for sideload distribution:
  - package root migrated from `com.walkerbrain.*` to `com.walkerxr.*`
  - `applicationId` is now `com.walkerxr.app`
  - install behavior is now **new install** (no in-place upgrade path from old package id)
- Android/app branding strings and theme naming updated to `Walker XR` (`Theme.WalkerXr`) while preserving feature behavior.
- Local debug APK naming changed from `walker-brain-v...` to `walker-xr-v...`.
- Startup Recovery guidance now shows explicit first-run import warning when no backup folder is configured.

## Companion updates merged from Walker-Desktop
For optimal Walker XR operation, companion desktop capabilities were introduced in parallel:
- Local desktop HTTP server + dashboard with LAN endpoints for optimizer run/schedule.
- Weekly scheduler and shared-folder bootstrap contract under `Walker-Shared`.
- Real `faster-whisper` backend integration for heavy transcription optimization.
- Runtime Whisper configuration controls (`model`, `device`, `compute type`, language handling) and persistent runtime config.
- Live progress/status endpoints and dashboard launch scripts (`start_agent.bat`, `open_dashboard.bat`).
- Architecture clarified: Walker XR acts as trigger/status UI; Walker-Desktop executes heavy optimization tasks.

## Feedback
This release established a cleaner system boundary: XR app for wearable interaction and desktop companion for heavier local compute. It set the naming and architectural direction for the next optimization-focused updates.
