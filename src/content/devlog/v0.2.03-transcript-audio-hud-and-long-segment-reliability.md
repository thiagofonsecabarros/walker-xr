## Release focus
Version **0.2.03 (2026-03-03)** focused on two practical outcomes:
- make transcript review fully in-app with integrated playback
- improve long continuous recording reliability so segments persist with usable transcript output

## HUDs impacted
- Voice Recorder HUD (Recent segments preview behavior)
- Audio Files HUD (single-tap transcript + audio flow)
- Files HUD (text/audio file opening behavior)
- Text Viewer HUD (new dedicated HUD)

## Added
- Added a dedicated **Text Viewer HUD** with full standard controls (move, minimize, resize, pin, reset, close).
- Added embedded audio playback controls in Text Viewer HUD:
  - Play / Pause
  - Seek timeline
  - Current time + total duration labels
- Added transcript recovery pipeline for blank saved segments:
  - DB transcript update support in `voice_recordings`
  - async single-item optimizer recovery (`sync audio -> run optimizer -> fetch transcript -> persist`)
- Added forced final decode hook to speech engine contract and Moonshine implementation support.
- Added additional wake variants for `Walker XR` phrasing.

## Changed
- Changed adaptive segment timing to:
  - `1-3 min` -> `10s` silence
  - `3-6 min` -> `3s` silence
  - `6-10 min` -> `1s` silence
  - hard stop at `10 min`
- Changed rollover flow to request/await final decode before adaptive or hard segment persistence.
- Changed Recent segments transcript preview to max **5 lines** with ellipsis for long entries.
- Changed Audio Files HUD rows from dual-button actions to **single-tap open** into transcript + audio viewer.
- Changed Files HUD open behavior:
  - text-like files open in-app Text Viewer HUD
  - audio recordings open transcript + audio viewer flow
  - transcript/audio cross-resolution is automatic when files are paired
- Changed external transcript callback path cleanup (in-app viewer is now primary).

## Fixed
- Fixed persistent `(no transcript)` outcomes on long recordings by combining:
  - decode wait-before-rollover
  - partial fallback at forced persistence
  - asynchronous optimizer transcript recovery
- Fixed silence-timing accuracy by anchoring silence calculations at VAD inactive transition.
- Fixed Text Viewer layering/focus ordering so it appears on top when opened.
- Fixed HUD preview/build signature mismatch after transcript callback removal.

## Feedback
This release materially improved day-to-day usability: transcript reading and playback now stay in one place, and long-session voice logging became more trustworthy under real test conditions.
