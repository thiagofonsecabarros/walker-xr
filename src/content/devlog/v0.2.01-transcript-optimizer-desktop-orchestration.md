## Release focus
Version **0.2.01 (2026-03-01)** delivered the first fully wired optimization loop between Walker XR and Walker-Desktop.

## HUDs impacted
- Settings HUD (Transcript Optimizer section, config/schedule dialogs, run summary)
- Audio Files HUD (optimizer state visuals, full datetime labels)
- Files HUD (latest-first file ordering, transcript optimization summaries)

## Added
- New **Transcript Optimizer** section in Settings HUD with:
  - `Run Optimizer`
  - `Set Schedule`
  - `Config`
- `DesktopOptimizerClient` integration for Walker-Desktop APIs (`/v1/sync/*`, `/v1/optimize/run`, `/v1/progress`, `/v1/recordings`, `/v1/jobs`).
- Optimizer config persistence:
  - Desktop IP
  - Force Re-run
  - minimum pending files threshold
  - schedule window (`From`/`To`)
  - charging requirement
  - retry-after timestamp
  - cached optimized keys
- Schedule/config dialogs and optimizer run summary fields (`last run`, `status`, `OK / Skipped / Failed`).
- Android networking support for local LAN calls (`INTERNET`, cleartext + network security config).
- File-level optimization state flags in voice history (`optimized`, `failed`).

## Changed
- Optimization moved from stub-only to real XR <-> Desktop orchestration:
  - sync payloads to desktop
  - trigger desktop job
  - poll progress and refresh HUD status
- Batch selection now includes **all unoptimized disk recordings** (not only recent 50), improving pending count accuracy.
- Scheduled behavior now enforces configured window/charging/threshold constraints, with startup evaluation + periodic checks + 30-minute retry on desktop failure.
- Backup/restore interplay now preserves known optimized markers to prevent unnecessary re-optimization loops.
- Audio Files HUD timestamp labels now use full datetime (`yyyy-MM-dd HH:mm`).
- Audio Files rows now color-code optimization state (teal optimized, red failed).
- Files HUD listing order for files is now latest-first (folder-first grouping preserved).
- Files HUD transcript visualization now includes optimization summaries (e.g., optimized/failed counters).
- Long-speech continuous safeguards were tightened with dynamic silence thresholds and hard rollover at 5 minutes.

## Notes
Walker-Desktop is now a required companion for transcript optimization in Walker XR. Walker XR remains the trigger/status surface; heavy Whisper processing runs on desktop.

## Feedback
This release made optimization operational in practice, not just planned. The XR app gained clear control and visibility, while desktop executes heavy compute where it is better suited.
