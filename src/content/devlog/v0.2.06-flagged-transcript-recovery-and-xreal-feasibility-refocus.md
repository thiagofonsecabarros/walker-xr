## Release focus
Version **0.2.06 (2026-03-10)** in Walker XR and **v0.0.3 (2026-03-10)** in Walker-Desktop marked a much larger transition point than a normal polish release.

Three tracks moved at the same time:
- improve transcript correction workflows inside the app
- add manual desktop review tooling for uncertain speaker assignments and segment cleanup
- validate whether deeper XREAL Unity SDK work was viable at this stage

The result was a more complete review loop from desktop inference to app-side inspection, and a clearer product decision: stabilize the current app baseline first, then revisit deeper spatial SDK experiments later.

## Systems impacted
- Files HUD
- Text Viewer HUD
- Settings HUD
- Walker-Desktop Dashboard
- Desktop speaker review and segment-management pipeline

## Notes
- Feasibility tests were run with the **XREAL Unity SDK** to understand realistic integration paths for spatial workflows.
- Those tests exposed device and runtime limitations that reduced the short-term value of pushing further into that path immediately.
- Based on that outcome, development was intentionally redirected toward finishing the stable app foundation before returning to more immersive XREAL Unity SDK work.

## Walker XR v0.2.06
### Added
- Added transcript flagging controls in Files HUD for optimized transcript JSON files.
- Added persistent flagged-key storage in HUD preferences so selected items can be revisited across sessions.
- Added structured transcript inspection improvements in Text Viewer HUD:
  - `Raw JSON` toggle
  - structured summary block for segments, speakers, language, confidence, model, and duration where available
- Added optimizer API support for `forcePendingKeys`, allowing flagged transcript items to be targeted in desktop re-optimization runs.

### Changed
- Changed optimizer run flow so flagged transcript keys are included in manual runs and single-item recovery calls.
- Changed optimizer status messaging to include flagged counts.
- Changed Files HUD transcript lookup and counting logic to support nested dated transcript folders recursively.
- Changed transcript file highlighting to include an explicit flagged visual state and action flow.
- Changed bundled local model and runtime assets under `app/src/main/assets`.

### Fixed
- Fixed Files HUD transcript and structured-payload resolution when transcripts live inside dated subfolders instead of transcript root only.
- Fixed stale flagged-key persistence by pruning flags when files are deleted or no longer belong to the optimized transcript set.

## Walker-Desktop v0.0.3
### Added
- Added a **pending review pipeline** for uncertain or flagged speaker assignments, with persisted review items carrying recording reference, timestamp, confidence, reason, and suggested speaker information.
- Added pending review APIs for listing, sampling, assigning, and dismissing uncertain speaker cases.
- Added speaker-segment management APIs for listing, sampling, moving, and deleting captured speaker segments.
- Added a more capable desktop dashboard editor with:
  - per-segment playback
  - reassignment controls
  - segment removal
  - pending review playback and assignment flow
- Added visual interaction polish in the dashboard with hover, focus, and press-state effects.

### Changed
- Changed dashboard version display to `v0.0.3`.
- Changed optimizer transcript output to tagged speaker lines (`[Speaker] text`) for stronger alignment between structured and human-readable outputs.
- Changed optimizer metadata flow to write `pending_review` when speaker assignment is not confident enough for automatic acceptance.
- Changed speaker merge semantics so the selected source speaker identity is preserved while target samples are merged into it.
- Changed segment sample extraction to use longer windows and more cluster-aware candidates for better evidence.
- Changed speech gate logic from a simple threshold to richer scoring metrics for stronger sample capture quality.

### Fixed
- Fixed dashboard refresh behavior that could reset merge or pending-review selections while the user was actively working.
- Fixed post-merge sample-count drift risks by recalculating profile sample and embedding state with safer fallbacks.

## Feedback
This release clarified several things at once. Transcript repair workflows needed more control inside the app, speaker diarization needed a real manual review surface on the desktop side, and the XREAL Unity SDK path was not yet mature enough to justify becoming the main implementation track right now. That combination made this a much bigger systems update than the app changelog alone would suggest.
